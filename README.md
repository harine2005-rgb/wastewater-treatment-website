# Wastewater Treatment Website

## About the Project
This project is a responsive frontend website developed to provide information about wastewater treatment, its processes, methods, and importance in protecting the environment.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Simple and user-friendly interface
- Responsive website design
- Easy navigation
- Informative content about wastewater treatment
- Interactive frontend elements

## Project Structure
```text
Wastewater-Treatment/
├── index.html
├── style.css
├── script.js
└── images/
```

## How to Run the Project
1. Download or clone this repository.
2. Extract the project files.
3. Open the project folder.
4. Open `index.html` in your browser.
